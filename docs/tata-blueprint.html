TATA 施工圖

給維護這座城市的人 · 2026-08 · 黑 / 白 / 琥珀,僅此三色

一句話

Tata 是一個本地優先的筆記城市:你每晚在像素筆記本裡寫字,字透過 Obsidian Local REST API 存進你自己的 vault;每一天的字長成一棟樓,每個月是一座島。Tata 沒有伺服器、沒有帳號、不收費——刪掉它,你的字一個都不少。

渲染管線(城市怎麼畫出來)

  • city/metrics.ts 讀 vault → 每檔算日期/字數/連結/標籤(Templates/、Letters/ 不入城)
  • city/plan.ts 確定性佈局:月份=7×6 街區(cellOf 同時是筆記本與海圖的格線)、蛇行排列、STREET=3 留出海峽
  • city/terrain.ts 逐街區距離場 → 每月一島、噪聲海岸線、夜海帶、跨島棧道
  • city3d.tsx Three.js 正交相機 → 量化後處理:8 階灰 + Bayer 抖動;aTint 通道旗標(琥珀焦點/樹葉/燈頭,互斥);ASCII sprite 圖集(居民/貓狗/樹/動畫點)
  • 筆記本本體 = 程式生成的 220×150 像素 SVG plate(封面/雙頁/書脊縫線/頁疊),內容以百分比疊上畫好的頁面;flex:none 鎖形狀
  • 字體:三個變數 --display/--ui/--mono 全指向 Cubic 11(CJK 點陣)+ Silkscreen

資料流:一個字的旅程

寫入敲鍵 → edit() → 0.4s 後草稿落 IndexedDB(安全網)→ 4s 靜止後 flush() → writeGuarded 先重讀 vault 比對 → 無人動過才寫入 → 成功後刪草稿。失焦 / 切背景 / 收書都會立即 flush。

開啟每次開啟領一個 epoch 序號;慢到的舊開啟一律作廢。「為某頁而開」的面板跳過「開今天」路徑。草稿優先於網路;唯有 HTTP 404 才給空白頁。

衝突兩邊都只是「往同一開頭續寫」→ 靜默合併;開頭分歧 → 三選:用他們的(我方留墓碑草稿)/ 用我的 / 兩者都留(另存副本,絕不覆蓋既有)。

tata.json寫入前必須「讀過 vault 副本」;讀不到/壞檔一律拒寫;遠端較新先合併。合併規則:數值取大、集合聯集、空值永不勝出(別台的空名字蓋不掉你的名字)。

守護不變式(改code前先背這些)

1 · 有字的檔案永不靜默覆蓋 —— writeGuarded 是唯一寫入門,新增寫入點自動繼承此律
2 · 只有 HTTP 404 才能呈現空白頁 —— 斷線不等於沒寫過
3 · 檔名+內容+基準版本 = 一個原子四元組 —— 永遠一起搬運,分開組裝=8/21 事故
4 · 動畫只讀狀態,永不延後/取消存檔 —— 先 flush,後闔書
5 · 關閉路徑只負責關 —— 畫面狀態一律在「下次開啟」時重設(否則淡出閃frame)
6 · 過去的頁面定稿唯讀 —— 要改historia,去 Obsidian
7 · 不懲罰斷更 —— earnedFloor 只升不降、刪筆記不縮城、缺月不留空島
8 · 三色鐵律 —— 黑/白/琥珀;像素=畫出來的結構(階梯圓、硬影、crispEdges),不是 CSS 濾鏡
9 · 中文使用者的觸發符號要收全形 —— :: 已收 ::,新觸發符照辦
