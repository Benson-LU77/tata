# ~/Claude/Tata 每個資料夾是什麼

> 逐一列出:裡面裝什麼、誰在維護、你要不要碰。
> ✅ = 你會用到 ✋ = 不要動(Claude 或機器管理) 👀 = 可以看,不用改

## 第一層總覽

| 資料夾/檔案 | 是什麼 | 碰? |
|---|---|---|
| `appstore/` | App Store 上架素材 | ✅ |
| `docs/` | 給人讀的文件(含本檔) | ✅ |
| `app/` | 全部程式碼 | ✋ |
| `ios/` | iPhone 外殼(Xcode 專案) | ✋(只有 Archive 上傳時照待辦開一次) |
| `public/` | 網頁版靜態素材(圖示、字型、隱私權頁) | ✋ |
| `scripts/` | 工具腳本(產 App 圖示、截圖框) | ✋ |
| `web/`、`worker/` | 網頁版殼與部署設定 | ✋ |
| `node_modules/`、`dist/`、`dist-web/`、`build/` | 機器產物,隨時可重生 | ✋ 永遠不用看 |
| `README.md` | GitHub 門面(英文) | 👀 |
| `deploy.command` | 雙擊=部署到 tata.page | ✅(平常 Claude 代勞) |
| `package.json`、`*.config.*`、`tsconfig*` | 工具設定 | ✋ |

## app/ — 程式碼(✋ Claude 維護;想看內容時的路標)

| 位置 | 裡面是什麼 |
|---|---|
| `app/page.tsx` | 主畫面:城市、會面、羅盤、所有面板的組裝處 |
| `app/lib/game/bonds-lines.ts` | **居民全部開場台詞**(325 句,分池/職業/階級) |
| `app/lib/game/bonds-answers.ts` | **每句台詞的專屬回話與收尾**(550 條問答) |
| `app/lib/game/replies.ts` | 主題回話池(備援)與人情委託回話 |
| `app/lib/game/bonds.ts` | 友好度規則(1/4/10/20 天分級)、對話記憶、選句引擎 |
| `app/lib/game/watts.ts` | 瓦特計價、夜間委託、等級 |
| `app/lib/game/shop.ts` | 補給站商品、遊戲存檔的讀寫合併 |
| `app/lib/city/` | 城市生成:筆記→建築、地形、示範城市 |
| `app/lib/i18n.ts` | 介面所有文字的中英對照表 |
| `app/components/` | 介面元件:`city3d.tsx` 城市渲染、`notes.tsx` 筆記本、`editor.tsx` 編輯器、`mirror.tsx` 鏡子 |
| `app/lib/game/__tests__/` | 測試(包含台詞覆蓋率護欄) |

**想改台詞?** 跟 Claude 說就好——每句開場都必須同步配回話,測試會擋沒配對的。

## ios/ — iPhone 外殼(✋)

只認識一個入口就夠:`ios/App/App.xcodeproj` = 送審時用 Xcode 打開的那個檔。其餘(Swift 外掛、打包好的網頁)都是 Claude 管。
