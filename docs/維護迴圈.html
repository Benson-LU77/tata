鐵則踩過的雷
改完必跑 tscvite build 不做型別檢查——曾漏 seed 欄位,鄰居三天都是預設臉
互動驗證用真實點擊,不用 JS .click().click() 繞過命中測試,曾漏掉「按鈕根本點不到」
改台詞必同步改 answers 鍵名測試強制 100% 覆蓋,鍵=開場句英文全文
新 sprite 必過 zz-sprite-guard一個非法字元=啟動全黑畫面(發生過兩次)
手機 CSS 覆寫一律放 globals.css 檔尾同權重後者贏,已踩 5 次
python 批次替換必加 assert無聲失敗兩次讓功能「半上線」

迴圈三 · 發版

通道步驟

隨改隨發		迴圈一全綠 → npm run deploy(CNAME 自動帶上,少了它網域會掉)→ 自己重整實測一次(SW 快取,必要時重整兩次)。PWA 是提示制更新,寫作中不打擾。
iOS App Storenpm run ios:sync(自動補回 VaultPlugin 註冊)→ Release 建置在模擬器過主流程(寫一頁→收書→相遇→補給站)→ Xcode:Build 號 +1 → Any iOS Device → Archive → Upload → 文案照 appstore-copy.md,隱私=不收集資料。
