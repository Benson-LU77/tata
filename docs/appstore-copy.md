## 描述(zh-Hant)

每天打開筆記本,寫一頁。寫完收進背包——你的字會變成一棟樓,亮起一盞燈。

Tata 是一座由你的筆記長成的像素城市。沒有帳號、沒有雲端、沒有訂閱:每一頁都是一個真正的 .md 純文字檔,存在這台裝置的文件夾裡,「檔案」App 打開就看得到、隨時帶得走。

- 像素筆記本:雙頁攤開、翻頁、書籤,支援 Markdown 與印章
- 字數點燈:寫得越多,今晚的城市越亮
- 完全離線:飛行模式照常寫,永遠不會轉圈圈
- 你的檔案:純 .md,存在 App 文件夾,iCloud 裝置備份自動涵蓋
- 不收集任何資料——沒有分析、沒有廣告、沒有「我們的伺服器」

桌機版在 tata.page,可直連 Obsidian 保管庫。

## Description (English)

Open the notebook, write a page, put it away — and your words become a building with its lights on.

Tata is a pixel city grown from your notes. No accounts, no cloud, no subscription: every page is a real .md plain-text file stored in this device's Documents folder — visible in the Files app, yours to take anywhere.

- A pixel notebook: two-page spread, page turns, bookmarks, Markdown and stamps
- Words become light: the more you write, the brighter tonight's city
- Fully offline: write in airplane mode, no spinners ever
- Your files: plain .md in the app's Documents folder, covered by iCloud device backup
- Collects nothing — no analytics, no ads, no "our server"

The desktop version at tata.page can connect straight to an Obsidian vault.

## 審查備註(App Review Notes 欄位,英文)

Tata is a fully interactive pixel-art journaling game, not a website wrapper: the entire experience (isometric city rendering, notebook, day/night cycle, in-game economy) runs offline from bundled assets, and all writing is stored as plain Markdown files in the app's own Documents directory via a native file plugin (visible in the Files app). No account, no network requests, no data collection. The web version at tata.page is a companion, not the content source.
