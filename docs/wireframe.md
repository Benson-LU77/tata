## 2. 筆記本(攤開的書)

```
┌────────────────────────────────────────────────┐
│            (城市在後面,調暗)                  │
│   ┌─────────────┬──┬─────────────┐◄旗 9/3     │ ← 書籤=書口燕尾旗(近5頁+[+])
│   │ 9月3日 週三 │書│ 今晚寫的字…▍            │
│   │             │脊│ 躺在稿紙橫線上           │
│   │ 7×6 月曆    │  │                          │
│   │ ▪▪▪▫▫…     │  │                          │
│   │ 132字·再68字│  │                          │
│   │ 多一層樓    │  │                          │
│   │ 今晚 +14W   │  │                          │
│   │ [B][☑][❝][⚑]│  │                          │ ← 工具列+釘告示板
│   │ ⚙保管庫     │  │                     [✓] │ ← 右下✓=收書(儀式)
│   └─────────────┴──┴─────────────┘            │
│         整本書=一張 220×150 像素底圖           │
└────────────────────────────────────────────────┘
```

- 左頁=資訊板(日曆、字數、樓層價、反向連結),右頁=純寫字。
- 過去頁「已定稿」唯讀;點背景=收書(桌機無 × 鈕;**手機右上有 X**,使用者指定例外)。
- 收書 → 琥珀光柱落成儀式(每日一次)。

## 9. 開場儀式(首訪流程)

```
信封(置中脈動) → 卡片[先看看示範城市]
  → 黑幕掀開,鏡頭 5s 緩降到路口
  → 你左顧右盼 → 自白
  → Ash 從左上走來(約 5s,停在你左側)→ 兩站對話
  → 「看到左下那顆星辰了嗎?點它。」→ 羅盤課(點一下前進)
  → 二選一:[我要開始寫了] / [先讓我逛逛]
```
