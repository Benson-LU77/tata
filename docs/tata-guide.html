TATA 使用說明書

寫字的人的夜城 · 產品介紹 / 上手 / 日常 / 維護

這是什麼

Tata 把你每晚寫的字,變成一座黑白像素的夜城。一天是一頁,也是一棟樓;一個月是一座島;寫得越多,樓越高、城越亮。它完全跑在你自己的電腦上——沒有伺服器、沒有帳號、免費,你的筆記存在你自己的 Obsidian 保管庫裡,Tata 只是那本會發光的筆記本。

世界觀三原色:黑、白、琥珀。
黑是夜,白是你的紙,琥珀是燈——只亮在重要的地方:今晚的樓、未讀的信、正在翻的那一頁。

第一次使用(約三分鐘)

  1. 在 Obsidian 安裝社群外掛 Local REST API,啟用它的 HTTP 伺服器,複製 API 金鑰
  2. 打開 Tata → 書的左頁底部 ⚙ 保管庫 → 貼上金鑰 → 連接
  3. 連上後,你過去的日記會直接長成一座城。開始寫今晚的第一頁吧

之後每次打開都會自動連線;Obsidian 要開著,城才是「live」的。

每晚的儀式

  1. 點左下羅盤最上面的背包 —— 筆記本攤開在城市上空
  2. 寫。右頁是稿紙,字會自己躺在格線上;左頁顯示日期、字數、離下一層樓還差幾個字
  3. 寫完,點書外任何地方 —— 字先存好,書飛回背包,城裡今晚那棟樓在琥珀光裡落成

介面地圖

左下 · 羅盤

位置功能
上(背包)打開今晚的筆記本
左(檔案櫃)翻檔找過去的日子——找到那天,書才翻開
右(鏡子)你的角色:換裝、取名
下(木箱)補給站:用瓦特換貓、狗、街燈、樹、天氣、地標…
中(帳冊)名冊:鄰居、好感度、信箱(有未讀信時亮琥珀點)

右上

放大鏡=搜尋(輸入時符合的建築會在城裡點亮);⋯=設定(聲音、全螢幕、Zen、診斷)。

畫面下緣

月份膠囊:◀ ▶ 在島與島之間航行;點月份開清單——每一天的頁面、字數,底部有一張海圖(所有島一眼看盡,點島啟航、點亮點開那一晚)。

書上

右書口的旗標=最近五頁++新頁(當前頁釘琥珀);點建築物也能直接翻開那天。

編輯器的小魔法

輸入效果
/指令選單:待辦、清單、標題、引言、分隔線、現在時刻、時光膠囊…
::(全形半形都可)像素印章:::貓:: ::太陽:: ::心::…直接蓋在字裡
[[連到另一頁(城裡兩棟樓之間會真的架起天橋)
#標籤標記主題,點了可搜尋
- [ ]待辦方框,點一下打勾(琥珀)
/capsule時光膠囊:寫給未來某天的自己,到期那天才能拆

城市的規則

  • 一天一頁:每晚的字進同一頁;多寫的隨手記會成為同一天的小樓
  • 字數=樓高,寫作的夜晚給你瓦特(W);連續寫,街燈更亮、瓦特更多
  • 過去的頁面已定稿——在 Tata 裡唯讀。真要修改歷史,請在 Obsidian 打開那個檔案(↗ 按鈕直達)
  • 永不懲罰斷更:斷了幾天,城不會縮小、瓦特不會扣、沒有枯萎的島。回來寫,就繼續長
  • 瓦特只能換「城市的樣子」(居民、天氣、地標),永遠買不到字

維護手冊

你的資料在哪裡

東西位置備份策略
你寫的每一頁你的 Obsidian vault(.md 檔)備份 vault 就是備份一切(iCloud/Git/Obsidian Sync 皆可)
遊戲存檔(名字、購買、好感、地標)vault 裡的 tata.json跟著 vault 一起備份
離線草稿、快取瀏覽器本機不用備份——送達 vault 前的字有草稿護著,送達後真相在 vault

換電腦 / 多裝置

新裝置連上同一個 vault,城市與存檔自動回來。兩台裝置同時用也安全:購買會合併、名字不會被空值蓋掉、筆記有防覆寫守衛。

更新 Tata

有新版本時右下角會出現 Update——按一下即可。若畫面行為怪異,先做這件事,再完全關閉重開一次。

疑難排解

過去的筆記打不開? 九成是 Obsidian 沒開或外掛睡著。開著 Obsidian 再點一次(系統會自動重試一次)。
跳出「衝突」三個按鈕? 表示這頁在 Obsidian 那邊也被改過。用他們的=採用對方(你的版本會留成草稿備份);用我的=以這邊為準;兩者都留=另存一份副本,最保險。
回報問題? 右上 ⋯ 設定面板最底部的 diagnostics 會列出最近的真實錯誤——截那張圖,勝過千言萬語。這些紀錄只存在你的裝置上。
想回到舊版素面板? 網址加上 ?oldnotes。
隱私? 一切都在你的機器上:字在 vault、草稿在瀏覽器、診斷不外傳。Tata 不連任何外部伺服器。
